# AGENTS.md

> Карта проекта для ИИ-агентов. Поддерживайте этот файл в актуальном состоянии по мере развития проекта.

## Обзор проекта
Демо-проект для демонстрации игрового ИИ с системами экипировки и анализа окружения.

## Технологический стек
| Технология | Решение |
|------------|---------|
| Движок | Unity 6 / C# 12 / URP |
| Архитектура | OOP |
| Async | Awaitable (Unity 6+) |
| UI | uGUI (MVP) |
| AI | Situation Analysis |

## Структура проекта
```
Assets/
├── Scripts/               [основная логика игры]
│   ├── AI/                [система анализа и принятия решений]
│   ├── Battleground/      [логика поля боя и отрисовки фигур]
│   ├── Units/             [параметры, инвентарь и атрибуты юнитов]
│   ├── UI/                [общие компоненты интерфейса]
│   └── ...
├── Scenes/                [сцены игры: Dungeon, IceMap, Menu]
├── Prefabs/               [префабы объектов и интерфейса]
├── Models/                [3D модели]
└── UI Toolkit/            [настройки UI]
Packages/                  [зависимости UPM]
ProjectSettings/           [настройки проекта Unity]
.unikit/                   [контекст ИИ-агента]
```

## Ключевые точки входа
| Файл / Объект | Цель |
|---------------|------|
| `Assets/Scenes/Menu.unity` | Главное меню (точка входа) |
| `Assets/Scenes/Dungeon.unity` | Основная игровая сцена |
| `Assets/Scripts/AI/SituationAnalyzer.cs` | Ядро логики ИИ |
| `Packages/manifest.json` | Зависимости пакетов |
