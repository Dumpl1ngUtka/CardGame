# Проект: Cards Game

## Обзор
Это небольшой демо-проект для демонстрации игрового ИИ. Игрок может спавнить юнитов, надевать на них экипировку для улучшения характеристик и добавления новых действий. Юниты принимают решения на основе анализа окружающей обстановки. Проект находится на стадии завершения, требуются архитектурные правки для подготовки к демонстрации.

## Основные возможности
- Спавн юнитов игроком.
- Система экипировки предметов, влияющая на характеристики и доступные действия.
- Игровой ИИ, принимающий решения на основе анализа окружения (SituationAnalyzer).
- Управление юнитами и взаимодействие с полем боя.

## Технологический стек
- **Движок:** Unity 6000.0.58f2 / C# 12 / URP
- **Архитектура:** OOP (объектно-ориентированное программирование)
- **Async:** Awaitable (встроенный async в Unity 6+)
- **UI Архитектура:** MVP (Model-View-Presenter)
- **UI Framework:** uGUI
- **Навигация:** AI Navigation (UPM)
- **Камера:** Cinemachine
- **Таймлайн:** Unity Timeline
- **Ввод:** Unity Input System

## Архитектурные заметки
- Скрипты организованы по функциональным модулям (AI, Battleground, Camera, Guild, Units и др.).
- ИИ базируется на системе анализа ситуации (SituationAnalyzer) и весовых точках (IAIWeightPoint).
- Система характеристик юнитов вынесена в отдельные компоненты (Attributes, UnitParameters, UnitResists).
